# Código de conduta

Este projeto adota o [Contributor Covenant 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/)
como código de conduta.

Em resumo: seja respeitoso, aceite críticas construtivas, foque no que é melhor para a comunidade e não tolere assédio
de nenhum tipo. Comportamentos inaceitáveis podem ser relatados de forma privada ao mantenedor pelo
[relato privado do GitHub](https://github.com/MathZiraA/Hermes-Sentinel-AIOps/security/advisories/new) ou pelo perfil
[@MathZiraA](https://github.com/MathZiraA). Todos os relatos são tratados com sigilo.
